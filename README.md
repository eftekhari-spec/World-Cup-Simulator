# World-Cup-Simulator
# 🏆 شبیه‌ساز جام جهانی ۲۰۲۶ (2026 World Cup Simulator)

یک برنامه شبیه‌ساز هوشمند و کاملاً شیءگرا (OOP) به زبان پایتون برای پیش‌بینی و شبیه‌سازی مسابقات جام جهانی ۲۰۲۶ براساس داده‌های واقعی، رنکینگ فیفا و مدل‌های آماری.

---

## 📌 درباره پروژه

این پروژه برای درس **برنامه‌سازی پیشرفته** طراحی شده است. هدف اصلی این برنامه، شبیه‌سازی کامل مراحل جام جهانی (مرحله گروهی تا فینال) با رعایت دقیق قوانین فیفا و محاسبه شانس قهرمانی هر تیم با اجرای هزاران باره شبیه‌سازی (روش مونت‌کارلو) است.

### ✨ ویژگی‌های کلیدی
- **شبیه‌سازی واقع‌گرایانه:** استفاده از **توزیع پواسون (Poisson Distribution)** برای تولید تعداد گل‌ها بر اساس قدرت حمله و دفاع هر تیم.
- **طراحی شیءگرا (OOP):** ساختار کاملاً پیاده‌سازی شده با ۵ کلاس مجزا و منطق تمیز.
- **رعایت کامل قوانین فیفا:**
  - سیدبندی و قرعه‌کشی ۴ گروهی.
  - تعیین رتبه‌بندی گروهی بر اساس امتیاز، تفاضل گل، گل زده و قرعه‌کشی در صورت تساوی کامل.
  - وقت‌های اضافه (با میانگین گل کمتر) و ضربات پنالتی (از جمله پنالتی‌های مرگ ناگهانی) در مراحل حذفی.
- **تحلیل آماری و شانس قهرمانی:** قابلیت اجرای ۱۰۰۰+ بار شبیه‌سازی برای استخراج درصد شانس قهرمانی هر تیم.
- **منوی تعاملی و کنترل خطا:** جلوگیری از کرش برنامه در صورت عدم رعایت ترتیب مراحل یا نبود فایل داده‌ها.

---

## 🏗️ ساختار و کلاس‌های برنامه

برنامه از ۵ کلاس اصلی تشکیل شده است:

| نام کلاس | وظیفه و مسئولیت |
| :--- | :--- |
| `Team` | نگهداری اطلاعات تیم (قدرت حمله، دفاع، رنکینگ)، آمار گل‌ها و محاسبه گل‌های متقابل در بازی |
| `Match` | برگزاری یک مسابقه بین دو تیم، ثبت نتیجه و به‌روزرسانی آمار و امتیازات |
| `Group` | مدیریت بازی‌های دور رفت ۴ تیم هر گروه و رتبه‌بندی دقیق جدول |
| `KnockoutStage` | برگزاری مسابقات مراحل حذفی (یک‌هشتم، یک‌چهارم، نیمه‌نهایی و فینال) |
| `WorldCupSimulator` | مدیریت کلی برنامه، خواندن داده‌ها، قرعه‌کشی، اجرای تورنمنت و محاسبه آمار کل |

---

## 📊 منطق شبیه‌سازی مسابقات (توزیع پواسون)

به جای تولید گل‌های کاملاً تصادفی، ابتدا **میانگین گل مورد انتظار** برای هر تیم بر اساس قدرت حمله خودی و قدرت دفاع حریف محاسبه می‌شود. سپس با استفاده از تابع `np.random.poisson` از کتابخانه **NumPy** تعداد گل واقعی بازی مشخص می‌شود.

---

## 🛠️ پیش‌نیازها و کتابخانه‌ها

برای اجرای این برنامه به پایتون نیاز دارید. کتابخانه‌های مورد استفاده:
- **NumPy** (`numpy`): برای شبیه‌سازی دقیق و سریع توزیع پواسون.
- **Random, CSV, OS**: کتابخانه‌های استاندارد پایتون برای قرعه‌کشی، خواندن فایل و مدیریت فایل‌ها.
